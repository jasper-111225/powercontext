# seekdb 概览

seekdb 是 OceanBase 推出的 AI 原生数据库，定位是把向量检索、全文检索和关系型数据放在同一个引擎里。它兼容 MySQL 协议，现有 MySQL 客户端、ORM 和 SQL 工具可以直接连接，因此业务系统不需要为了向量能力再引入一套独立的向量数据库。

seekdb 有两种使用方式。第一种是嵌入式模式，数据库以库的形式链接进应用进程，适合桌面应用、CLI 工具和单机服务，数据目录通常是一个本地路径。第二种是服务器模式，seekdb 以独立进程运行并监听端口（默认 2881），应用通过 MySQL 协议连接。本知识库示例使用服务器模式，方便浏览器应用与数据库进程分离部署。

在 AI 能力方面，seekdb 提供 VECTOR 类型、HNSW 向量索引、FULLTEXT 全文索引，以及 DBMS_HYBRID_SEARCH 这样的混合检索函数。向量索引支持 cosine、l2 和 inner_product 三种距离度量；全文索引支持 space、ngram、ngram2、beng、ik 等分词器，其中 ik 适合中文分词。

对端侧 AI 应用来说，seekdb 的价值在于数据边界清晰：用户文档和向量都留在本地数据库里，浏览器只负责把文本编码成向量，数据库负责存储、索引和排序。这样既满足了隐私要求，也避免了把检索逻辑拆成两套系统。

seekdb 的版本可以通过 `SELECT VERSION()` 查看，返回结果类似 `5.7.25-OceanBase seekdb-v1.4.0.0`。这个版本号同时说明了 MySQL 兼容版本和 seekdb 自身的版本，排查驱动兼容性问题时很有用。

在部署上，seekdb 允许通过参数控制数据文件、日志盘、内存等资源。单机演示通常给 1GB 数据文件和 2GB 日志盘即可；生产环境再按数据量调整。需要注意的是，长期运行的实例不要随意重装，否则实例标识会变化，依赖该标识的遥测或授权状态可能失效。
