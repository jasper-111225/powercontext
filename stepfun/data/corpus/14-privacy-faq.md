# 隐私、离线与常见问题

**文档会上传到云端吗？** 不会。浏览器读取文件后，在本地完成分块和向量化，只把文本和向量发给本机运行的 Node 服务，再由服务写入本机 seekdb。整个过程没有调用任何云端推理接口。如果应用部署在远程服务器，文本会经过局域网或公网传输到数据库，但模型推理仍然发生在浏览器，且部署方应明确告知数据传输范围。

**模型文件从哪里来？** 来自 Hugging Face 上 `Xenova/bge-small-zh-v1.5` 的 ONNX 转换版，ModelScope 有同一仓库的镜像。本项目下载 FP32 权重后自行做 INT8 动态量化，量化后的文件随应用一起分发，运行时不访问模型仓库。

**为什么第一次打开很慢？** 首次需要下载约 24MB 的 INT8 模型、初始化 ONNX Runtime、编译 WebGPU shader 或加载 WASM 模块。加载完成后会做一次预热推理，之后的查询只需要几十毫秒。模型文件带 HTTP 缓存，第二次打开会快很多。

**没有 WebGPU 怎么办？** 应用会自动降级到 WASM，界面顶部会显示黄色提示和当前后端。WASM 路径使用多线程（需要跨源隔离）和 SIMD，单条查询通常在几百毫秒内完成，功能与 WebGPU 完全一致。

**为什么检索结果里有不相关的文档？** 全文检索按词项匹配，中文分词可能把一个词拆成更小的单位，导致部分匹配；向量检索则可能因为语义泛化召回相近主题。混合检索用 RRF 融合两路，通常能把真正相关的结果排在前面。可以切换“向量”或“全文”模式对比两路效果。

**支持图片吗？** 当前版本聚焦文本知识库。图片需要多模态模型（如 CLIP）生成向量，索引结构可以复用，但模型体积和推理成本会明显增加，因此没有纳入基础版本。

**数据存在哪里？** 存在本机 seekdb 的数据库目录里，集合名形如 `kb_xxxxxxxx`，包含向量列、原文和 JSON 元数据。删除知识库会删除对应集合及其索引。
