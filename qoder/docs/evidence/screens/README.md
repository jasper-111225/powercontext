# 截图目录

本目录用于存放**实际运行页面**的截图。页面截图需要 seekdb、Ollama 与 PowerContext
同时在线，而生成环境的服务并不随仓库分发；Qoder 会话截图则随任务卡完成逐张收录。

> 不要用占位图、设计稿或生成图片代替真实截图；评审会对照页面与日志核对。

## 采集步骤

```bash
# 1. 三个服务都在线
curl -s http://127.0.0.1:8766/api/health
scripts/pc_server.sh status

# 2. 打开页面，按 docs/验证样例.md 场景 1–7 操作
#    浏览器窗口建议 1440×900，保留地址栏与时间信息

# 3. 截图放到本目录，文件名与上表一致
```

`docs/验证样例.md` 与 `docs/提交材料.md` 引用了这些文件名，补齐后链接即可生效。
