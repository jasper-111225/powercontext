# 运行说明

> 目标：一位没接触过本项目的评审，按本文从零跑起来，并在浏览器里完成一次「有引用的提问」。

## 1. 环境要求

| 组件 | 版本（验证环境） | 默认地址 | 用途 |
|---|---|---|---|
| seekdb | `5.7.25-OceanBase seekdb-v1.4.0.0` | `127.0.0.1:2881` | 资料、片段、向量/全文索引、问答日志、笔记 |
| Ollama | 0.40.x | `127.0.0.1:11434` | 向量模型；可选生成模型 |
| Python | 3.12（>=3.10） | — | 后端 |
| PowerContext | 1.4.0 | `127.0.0.1:17430` | 学习记忆 |
| 浏览器 | Chrome / Firefox 近两年版本 | — | 前端 |

系统依赖：`pymysql`、`pypdf`、`fastapi`、`uvicorn` 等由 `pyproject.toml` 安装，无需系统级库。

### 1.1 seekdb

如果已按赛题一部署过 2881 实例，直接复用。检查：

```bash
python - <<'EOF'
import pymysql
c = pymysql.connect(host="127.0.0.1", port=2881, user="root", password="", charset="utf8mb4")
cur = c.cursor(); cur.execute("SELECT VERSION()"); print(cur.fetchone())
EOF
```

没有实例时，按 seekdb 官方文档启动一个 1.4.x 实例并监听 2881。
本项目只依赖 MySQL 协议、`VECTOR` 类型、`FULLTEXT ... WITH PARSER ik`、`cosine_distance()`、`MATCH ... AGAINST`、`JSON`。

### 1.2 模型

```bash
ollama pull qwen3-embedding:0.6b     # 必需，1024 维
ollama pull qwen2.5:0.5b             # 可选；没有也能跑（自动用原文摘录）
```

首次调用会把模型载入内存，第一条向量请求可能 10–20 秒，之后 0.3–3 秒/条（视机器负载）。仓库内置了演示语料的向量缓存，首次灌库通常不到 1 分钟。

### 1.3 PowerContext

```bash
uv tool install "powercontext[cli,server]==1.4.0"
# 或在已有环境里：
python -m pip install "powercontext[cli,server]==1.4.0"
```

`scripts/pc_server.sh` 会优先使用 `PATH` 里的 `powercontext`，其次 `../../.toolchain/bin/powercontext`、`~/.local/bin/powercontext`；
也可用 `POWERCONTEXT_BIN=/path/to/powercontext` 指定。

## 2. 安装与启动

```bash
cd qoder

# ① 虚拟环境 + 依赖
uv venv --python 3.12 .venv
uv pip install -e ".[dev]"

# ② 建库 + 灌入示例语料（内置缓存，通常 <1 分钟；删缓存后重灌约 8–20 分钟）
.venv/bin/python scripts/seed.py

# ③ 启动记忆服务（独立进程）
./scripts/pc_server.sh start

# ④ 启动 Web
./scripts/run.sh
```

打开 <http://127.0.0.1:8766>。

也可以一步到位：`./scripts/setup.sh`（内部执行 ①②，并做 seekdb / 向量模型连通性检查）。

### 2.1 配置

所有配置走环境变量，默认值见 `app/config.py`；可复制 `.env.example` 为 `.env`，`scripts/run.sh` 会自动加载。

| 变量 | 默认 | 说明 |
|---|---|---|
| `JUDIAN_DB_HOST/PORT/USER/PASSWORD/NAME` | `127.0.0.1/2881/root/空/judian` | seekdb |
| `JUDIAN_EMBED_BASE/MODEL/DIM` | Ollama / `qwen3-embedding:0.6b` / 1024 | 向量 |
| `JUDIAN_LLM_BASE/MODEL` | Ollama / `qwen2.5:0.5b` | 生成模型；默认 `JUDIAN_LLM_ENABLED=false`，需要改写时再开 |
| `JUDIAN_POWERCONTEXT_URL/TOKEN` | `http://127.0.0.1:17430` / `judian-local-token` | 记忆 |
| `JUDIAN_PORT` | 8766 | Web 端口 |
| `JUDIAN_EVIDENCE_TOP_N` | 8 | 送入作答的片段数 |
| `JUDIAN_MIN_VECTOR_SIM` | 0.28 | 拒答阈值之一 |

> 换模型时注意同步 `JUDIAN_EMBED_DIM`，并重建索引（`scripts/seed.py --reset`）。

## 3. 数据初始化与重置

```bash
# 增量：同一 source 覆盖旧片段，保留其他资料
.venv/bin/python scripts/seed.py

# 清空资料与片段后重灌（保留问答历史、笔记、记忆）
.venv/bin/python scripts/seed.py --reset

# 只灌某类文件
.venv/bin/python scripts/seed.py --only 'build-*.md'
```

语料目录：`data/corpus/`；中文标题在 `data/corpus/manifest.json`。
往网页「资料库 → 导入资料」上传也可以，文件会落到 `data/uploads/`。

## 4. 页面怎么用

1. **提问**：首页输入问题，Enter 发送；勾选「详细」会要求更长的回答（模型可用时）。
2. **看证据**：右侧每张证据卡显示来源、标题路径、页码、向量排名 / 全文排名 / RRF 分数；
   正文里的 `[n]` 会高亮对应卡片；点卡片或「查看完整原文」展开未截断原文。
3. **看检索轨迹**：证据面板底部「检索轨迹」展开两路 Top-10。
4. **记忆**：右上角「我的学习记忆」填写研究主题、目标、偏好；写入后首页会出现「我记得…」横幅。
5. **资料库**：查看每篇资料的片段数、字符数，移除资料。
6. **评测**：读取 `docs/evidence/eval.json`，展示指标与逐题结果。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| `seekdb 连接失败` | 确认 2881 在跑、root 密码为空；改 `.env` |
| `调用向量模型失败` | `ollama list` 是否有 `qwen3-embedding:0.6b`；首次加载慢，等一会 |
| 答案总是「原文摘录」 | 正常：0.5B 模型常不守引用格式，系统按设计回退；换更大模型可提高 `llm` 比例 |
| 页面显示「记忆：本地暂存」 | `scripts/pc_server.sh status`；未启动时功能降级，不影响问答 |
| 导入 PDF 没内容 | 扫描件无文本层，需要 OCR（当前未内置） |
| 端口冲突 | `JUDIAN_PORT=8767 ./scripts/run.sh`；PowerContext 用 `JUDIAN_POWERCONTEXT_PORT` |
| 首次灌库很慢 | 每条文本都要过 CPU 向量模型；仓库内置演示语料缓存，通常 <1 分钟。删除 `data/embed_cache.json` / `.runtime/embed_cache.json` 后才会重新向量化 |
