## 3. 评审 10 分钟复现路径

```text
1. clone 仓库，cd qoder
2. 确认 seekdb 2881、Ollama、PowerContext 1.4.0 就绪（docs/运行说明.md §1）
3. ./scripts/setup.sh          # 装依赖 + 建库 + 灌 9 篇语料
4. ./scripts/pc_server.sh start
5. ./scripts/run.sh            # 打开 http://127.0.0.1:8766
6. 按 docs/验证样例.md 场景 1–6 操作
7. 可选：python scripts/eval.py；python scripts/verify.py --require-memory
```

## 4. 使用效果

当前**没有外部真实用户**，因此不提交使用人数/问卷等数据，避免虚构。
可核对的数据只有：

- 固定题集：23 题（20 可答 + 3 不可答），指标见 [`docs/evidence/eval.md`](evidence/eval.md)；
- 端到端验收：`docs/evidence/logs/verify-*.md`；
- 本机运行环境与耗时：4 核 / 9.7 GB / 无 GPU，端到端 0.6–1.5 s（抽取式）。

如果后续有同学/同事试用，建议补充：

| 内容 | 采集方式 |
|---|---|
| 使用人数 / 次数 | `queries` 表按 `user_id` 统计；Qoder Sites 访问统计 |
