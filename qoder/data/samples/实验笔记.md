# 实验笔记

## 2026-10-22 · 一个坑

在容器里跑 `./build.sh release --init` 时，依赖下载卡在 73%，重试后命中缓存才继续。
把依赖缓存目录挂到宿主机后，重建容器不用重新下载；但不要把 `build_release/` 挂进去，
否则 CMake 缓存里的绝对路径会和容器内路径冲突。出错时直接删掉 `build_release/` 重新配置。

## 2026-10-24 · 编译产物

Release 构建完成后，产物在 `build_release/src/observer/seekdb`；Sanity 构建用
`./build.sh sanity --init --make`，产物在 `build_sanity/src/observer/seekdb`。
调试 core dump 时要用生成该文件的同一二进制，先用 `file` 确认架构，
再 `gdb build_release/src/observer/seekdb core` 打开。（本地环境已验证）
